# 게임 기법 카드뉴스

공개 소스와 개발자 발표로 확인한 게임 기법을 1080×1350 카드뉴스로 정리해 모은 정적 허브입니다.

- 보기: https://saltlake00.github.io/game-tech-cardnews/
- 표지를 누르면 한 장씩 넘겨 볼 수 있습니다(←/→, Esc). 주소 `#<카드뉴스>/<장>`으로 특정 장을 바로 엽니다.
- 도식은 모두 직접 그렸습니다(HTML·SVG). 게임 화면과 발표 슬라이드는 넣지 않았고, 출처는 각 카드뉴스 마지막 장에 적었습니다.
- 게임 이름과 발표 이름은 출처를 밝히려고 적었습니다. 각 게임·발표의 권리는 해당 권리자에게 있습니다.

## 갱신

이 저장소는 생성 결과만 담습니다. 원본은 비공개 작업 폴더에 있고, 그쪽 생성 스크립트가 내부 메모를 지운 공개본을 이 폴더에 씁니다.
쓸 때 로컬 경로·내부 문서 경로·이메일 같은 흔적이 하나라도 남아 있으면 멈춥니다.
